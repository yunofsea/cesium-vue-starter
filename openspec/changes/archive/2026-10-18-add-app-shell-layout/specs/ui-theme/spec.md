# Spec Delta

## Purpose

让界面在浅色与深色环境中保持一致的信息层级与可读性，并允许用户控制界面的明暗表现。

## ADDED Requirements

### Requirement: 主题模式

系统 SHALL 提供浅色、深色与跟随系统三种主题模式，默认使用跟随系统。

#### Scenario: 首次使用

- **WHEN** 用户首次打开应用且没有历史选择
- **THEN** 主题为跟随系统
- **AND** 界面表现与操作系统当前的明暗设置一致

#### Scenario: 手动切换

- **WHEN** 用户依次切换主题模式
- **THEN** 顺序为浅色、深色、跟随系统并循环

### Requirement: 跟随系统的实时更新

主题为跟随系统时，系统明暗设置变化 MUST 在不刷新页面的情况下应用到界面。

#### Scenario: 系统切换到深色

- **WHEN** 主题为跟随系统且操作系统从浅色切换到深色
- **THEN** 界面在无需刷新的情况下切换为深色

### Requirement: 主题持久化

用户选择的主题模式 MUST 被保存，并在下次打开应用时恢复。

#### Scenario: 重新打开应用

- **WHEN** 用户选择深色后关闭并重新打开应用
- **THEN** 界面以深色呈现

### Requirement: 首屏无主题闪烁

页面首次绘制前 MUST 已应用正确的主题，任何情况下 MUST NOT 出现与应用主题相反的底色闪烁。

#### Scenario: 深色模式冷启动

- **WHEN** 已保存深色主题的用户重新加载页面
- **THEN** 首帧即为深色背景
- **AND** 不出现白色闪屏

### Requirement: 全局一致的明暗切换

主题切换 SHALL 同时作用于顶部工具条、图标栏、工具面板、状态栏、下拉菜单、滑杆与图例。

#### Scenario: 深色下打开面板

- **WHEN** 主题为深色且用户打开任一工具面板
- **THEN** 面板、控件与状态栏均呈现深色表现
- **AND** 没有残留的浅色控件

### Requirement: 文字与控件对比度

两套主题下，正文文字的对比度 MUST 不低于 4.5:1，图标与控件边界的对比度 MUST 不低于 3:1。

#### Scenario: 深色主题对比度

- **WHEN** 在深色主题下测量面板正文文字与其背景
- **THEN** 对比度不低于 4.5:1

#### Scenario: 浅色主题对比度

- **WHEN** 在浅色主题下测量面板正文文字与其背景
- **THEN** 对比度不低于 4.5:1

### Requirement: 浮层与画布的可区分性

工具面板在两种主题下 MUST 与三维画布明确区分：浅色主题通过实心底色与阴影，深色主题通过半透明底色与边框。

#### Scenario: 浅色主题下的面板

- **WHEN** 浅色主题且面板浮在明亮的画布上
- **THEN** 面板边缘通过边框与阴影与画布形成可辨识的边界

### Requirement: 内置版权控件适配

Cesium 内置的版权与提示控件在深色主题下 MUST 保持足够对比度，不得出现深底深字。

#### Scenario: 深色主题下的版权信息

- **WHEN** 主题为深色
- **THEN** 版权信息文字与其背景对比清晰

### Requirement: 减少动态效果

操作系统启用「减少动态效果」时，界面 MUST 禁用或显著缩短非必要的过渡动画。

#### Scenario: 启用减少动态效果

- **WHEN** 操作系统开启减少动态效果且用户开合面板
- **THEN** 面板不播放位移动画
